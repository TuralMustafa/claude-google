Privacy Policy

Last updated: November 17, 2026

Claude Google Connector is a personal, single-user application. Its only user is its owner, who connects it to their own Google account.

What data is accessed

With the owner's consent, the application can read and modify the owner's Gmail, Google Drive, Google Calendar, Google Docs and Google Sheets data. It does so only when the owner asks Claude Code to perform a task.

How data is used

Data is used only to carry out the owner's own requests. To do this, the relevant content is processed by the AI assistant (Anthropic's Claude) that the owner uses. Data is not sold, not used for advertising, and not shared with anyone else.

Storage

OAuth tokens are stored only on the owner's own computer. No data is stored on any server operated for this application.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
